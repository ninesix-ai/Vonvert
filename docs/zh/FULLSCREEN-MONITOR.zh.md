# 全屏监视器

> 语言：[English](../FULLSCREEN-MONITOR.md) · 简体中文

Vonvert 在你说话的同时改变你的声音。**全屏监视器**是一个独立窗口，把当前声音的状态画成图。你可以用它在上播前检查音质、在录制时盯住音量，或者把它当作直播画面。

本指南说明每块图形的含义、窗口操作方法，以及如何接入 OBS。

## 1. 监视器是什么，不是什么

**它是你声音的仪表盘。**就像汽车的转速表、油表和时速表，只不过测的是你嘴巴发出的东西。它显示四项来自你电脑真实音频的测量结果。

**它不是：**

| 不是这个 | 为什么重要 |
|---|---|
| 编辑器 | 这里不能选区、放大、剪辑或修复音频。这些要用音频编辑器。 |
| 报警器 | 数值不对时不会弹窗。图形给你看，判断由你做。 |
| 推流器 | 它不直播、不编码，只在屏幕上画图。 |
| 声音来源 | 这个窗口**不带声音**。见 [§7 接入 OBS](#7-接入-obs)。 |

主窗口里那条小频谱条照旧保留，它只用来一眼确认"我有声音"。想看细节时才打开监视器。

## 2. 打开、移动、关闭

**打开：**主窗口右上角的四角外扩箭头图标（鼠标停上去显示"全屏监视器"）。再点一次只会把监视器移到最前，不会重复开窗。

**移动：**按住鼠标左键拖动窗口任意位置。这个窗口没有标题栏，所以拖动黑色区域就是移动它。

**关闭：**按 `Esc`，或点**关闭**按钮。

**显示按钮：**移动鼠标。右下角会出现一条小工具条。鼠标停下约 3 秒后，工具条和鼠标箭头一起消失，保证采集画面干净。

| 按钮 | 作用 |
|---|---|
| **关闭** | 关闭监视器。主窗口继续运行。 |
| **保持置顶** | 打开或关闭"总在最前"。当监视器挡住你要点的东西时，关掉它。 |
| **窗口尺寸** | 依次切换 1280×720 → 1920×1080 → 铺满工作区。它不会盖住任务栏。 |
| **恢复默认视图** | 把布局、尺寸和置顶恢复成默认值。 |
| **专业术语** / **说人话** | 在通俗用词和音频行业用词之间切换面板标题，见 [§3](#3-四块画面分别在说什么)。 |
| **帮助** | 打开一张小卡片，列出所有手势和最该看的数值。 |

窗口第一次打开时是 1280×720，你可以拖拽边缘改变大小。之后它会回到你上次离开时的大小和位置，并且继续显示同一路声音、同一个响度目标和同一种用词——所以为 OBS 摆好的位置会带到下一场直播。点**恢复默认视图**可回到默认状态。如果保存的位置在一台已经拔掉的显示器上，窗口会开在主屏中间，而不是你够不到的屏幕外。

**这些操作现在都写在界面上，不再需要事先知道：**每块面板都带一个小标签按钮——点它，或双击面板本身，该面板就会铺满整窗。铺满时被遮住的面板不会消失，窗口底部会把它们列成一条按钮，点一下就回来，所以不必知道“再双击一次”这个手势。单击面板本身不会改变布局，所以直播中不会误触弄乱画面。窗口每次打开时还会用几秒提示三个手势（拖动移动、双击放大、右下角更多按钮），然后自行淡出。

## 3. 四块画面分别在说什么

窗口默认使用通俗标题，专业名以小字显示在下方。点**专业术语**按钮可把两者主次对调。

| 面板标题（通俗） | 专业名 | 回答的问题 | 怎么看 |
|---|---|---|---|
| **声音细节** | 语谱图 | 我的声音里有没有不该有的东西？ | 左边是几秒前，右边是现在。下方是低音，上方是高音。越亮代表那个音高上能量越大。 |
| **声音形状** | 波形 | 变声有没有改变我声音的形状？ | 你说话时线条上下摆动。摆动越大代表那一瞬间越响。 |
| **音量** | 响度（LUFS） | 我太轻还是太响？ | 一根竖表，三个标记。盯紫色那个。见 [§6](#6-响度数值怎么读)。 |
| **音高标记** | 音分 / 音符 | 我跑得调了吗？ | 音符名 + 音分数 + 颜色：绿色接近，黄色还行，红色跑调。 |

两点需要知道：

- **频率轴已有刻度，但不是均匀分布。**下方是低音、上方是高音，右边缘是现在。图上标出“你声音的主要区域”的那一段才是关键；它以上主要是嘶声、“s”音和房间噪声——这正是为什么看起来最热闹的区域并不是最重要的区域。
- **横向窗口显示的约是 4 秒的声音**，不是一分钟。

### 声音细节：图形代表什么

| 你看到 | 通常是什么 | 可以怎么做 |
|---|---|---|
| 底部一条亮带随说话起伏，其余全暗 | 正常的人声 | 无需处理，这是健康的画面 |
| 顶部一条细亮线在你不说话时也存在 | 电源嗡声、风扇、空调 | 挪开麦克风，关掉风扇，靠近麦克风说话 |
| 每次发"s""t"时顶部出现亮点 | 齿音（刺耳的"s"音） | 变声后很常见；从麦克风和房间入手解决 |
| 不说话时整张图布满细小亮点 | 麦克风收进了房间噪声 | 铺软装、关窗、靠近麦克风 |
| 说完话后亮带缓慢拖长消失 | 房间回声（混响尾） | 空房间的正常现象；地毯和窗帘能减轻 |
| 变声后的声音多出条纹或金属感 | 变声算法自身的伪影 | 换一个预设，或减小音高偏移幅度 |

### 声音形状：对比处理前后

面板旁两个按钮决定这块图画的是哪一路：

| 按钮（通俗） | 专业名 | 是什么 |
|---|---|---|
| **你的原声** | 干声 | 麦克风未经改变的信号 |
| **变声后** | 湿声 | 听众实际收到的信号 |

这两个按钮**只改变画面，不改变输出**：无论选哪个，听众听到的都是变声后的声音。按钮下方一行小字会一直写明当前看的是哪一路。

为什么要对比：在两者之间来回切换，看形状变化。形状相近、只是音高被整体搬动，通常说明变声比较自然。波形上下被削平（线条顶部底部像是被切掉）说明信号撞到上限，听众会听到破音——请降低输入增益或离麦克风远一些。

## 4. 先只看一个数值

你不需要同时读四块图。记住一条规则就够：

> **音量表上紫色标记应当落在绿色横线附近。**

- 紫色标记明显**低于**绿线 → 你太轻，听众需要自己拧大音量。
- 紫色标记明显**高于**绿线，并且 **TP** 数值接近 0 → 有爆音风险。离麦克风远一些或降低输入电平。
- **黄色**标记是整段的平均值。只在录制结束时看它，开始新段落时把它重置。
- **青色**标记每零点几秒就跳一次。不用管它，看它只会让你紧张。

注意：绿线标的是一个**目标**，读数下方的按钮可以切换目标：**广播 -23**、**流媒体 -14**、**播客 -16**，或隐藏目标线。选与你音频发布去向一致的那个。线上会标出自己的数值，所以永远能看清自己对准的是哪个目标。

## 5. 开播前的四项快查

| 检查项 | 绿灯 | 黄灯 | 红灯 |
|---|---|---|---|
| **音量**（紫标记、`TP`） | 紫标记与绿线相差 3 以内；`TP` 为 -2 或更低 | 相差 3–6；`TP` 接近 -1 | 相差超过 6，或 `TP` 到 0 及以上 |
| **干净度**（声音细节） | 不说话时画面基本全暗 | 不说话时顶部一条细线 | 不说话时满屏亮点 |
| **自然度**（两种声音对比） | 形状相近，只是音高被搬动 | 变声后明显多嘶声或金属感 | 波形顶部被削平 |
| **音准**（标记颜色） | 基本为绿色 | 黄色居多 | 红色常驻 |

一句话记忆：**暗 = 安静，亮 = 你在说话，颜色 = 好或不好。**

## 6. 响度数值怎么读

这个窗口用 **LUFS** 计量音量。听众判断"响不响"靠的是平均值，不是瞬时峰值；LUFS 就是衡量这个平均值的国际标准。各流媒体平台也用同一个标准来拉平它们承载的所有内容。

| 表上的东西 | 含义 | 用来做什么 |
|---|---|---|
| 量程底部 -60 到顶部 0 | 越往上越响。全是负数，这点常让人困惑。 | 记住"上 = 响，下 = 轻" |
| **青色标记**（瞬时） | 大约最近 0.4 秒 | 看你的音量跳得有多厉害 |
| **紫色标记**（短期） | 大约最近 3 秒 | **你实际该盯的那根** |
| **黄色标记**（综合） | 整段录音的平均值，只累计不倒退 | 跨集数对比音量是否一致 |
| 绿色横线，标 **-23** | 广播目标（EBU R128） | 只是参考，未必是你的平台目标 |
| `TP -x dBTP` | 真实峰值：离削顶还有多远。到 0 及以上会破音。 | 最响的一句也要保持 -1 或更低 |
| `综合响度 -x LUFS` | 黄色标记的数字版 | 发布前记下来 |

三根标记在表上标了 **M**、**S**、**I** 字母，不必再猜哪根是哪根；量程也标了数值（越往上越响，而且全是负数）。`TP` 行在接近上限时变琥珀色、超过后变红色，并且用文字说出来，不只靠颜色。

**为什么重要：**如果录制太响，平台会整体压低，你的声音在听众耳机里就变小、变远；如果太轻，有些平台不会帮你放大。音频发布并被平台二次编码之后无法挽回，所以边录边看音量，才是省掉"重录一遍"的关键。

**重置整段平均：**数字下方的按钮会让计数重新开始，这样你可以一段一段地量。右键点那行数字也能做同一件事。

## 7. 接入 OBS

**OBS 是什么：**OBS Studio 是一款免费软件，把游戏、摄像头、图片和其他程序窗口层层合成成一格画面，再推给你的直播平台。

**为什么要采集这个窗口：**画面来自你的真实声音，观众看到的就是你听起来的样子。它不花钱、不用订阅，而且切换音色时淡入的预设名正好当作直播字幕用。

**设置步骤：**

1. 在 Vonvert 里打开监视器。
2. 在 OBS 的"来源"里点 **+ → 窗口采集**。
3. 在窗口列表里选中 Vonvert 窗口。
4. 拖红色控制点让它铺满画布，或右键该来源 → 变换 → 适配屏幕。
5. 让鼠标静止 3 秒，箭头和工具条会从采集画面里消失。

**两种用法：**铺满整个画布（电台式、口播类节目），或者缩成游戏直播角落的小窗。

**采集不带声音。**窗口采集只抓像素。你的变声要通过虚拟音频线进入 OBS，这是另一件事：添加**音频输入捕获**并选择 `CABLE Output (VB-Audio Virtual Cable)`。如果直播有画面没声音，原因就在这里。见[虚拟音频设备设置指南](VB-CABLE.zh.md)。

**画面清晰度：**监视器打开时是 1280×720。如果 OBS 画布是 1920×1080，画面会被放大因而发虚。请用**窗口尺寸**按钮切到 1920×1080，或把画布设为 720p。

**如果 OBS 采到黑屏或空白：**在窗口采集属性里，把**采集方式**改为"Windows 10（1903 及以上）"。

## 8. 首次导览与帮助卡

第一次打开监视器时，它会带你走四站——大图是什么、哪根标记是你的音量、怎么对比原声与变声后、按钮在哪里。点任意处进入下一站，点**跳过**直接结束。之后不再出现。

右下角工具条上的**帮助**按钮随时可以把这些信息收回一张小卡里：全部手势，以及最该盯的那个数值。

如果想在看完之后再次看到导览，请删除 Vonvert 数据目录里的 `fs_monitor_tour_done` 文件（默认位置
`%APPDATA%\ninesix-ai\Vonvert`）。

## 9. 鼠标与键盘

| 操作 | 怎么做 |
|---|---|
| 移动窗口 | 按住任意处拖动 |
| 关闭 | `Esc`，或**关闭**按钮 |
| 让某个面板铺满窗口 | 点面板上的标签按钮，或双击该面板；底部的按钮条能把被遮住的面板叫回来 |
| 对比原声与变声后 | 声音形状面板下方两个按钮 |
| 改变大小 | 拖窗口边缘 |
| 布局搞乱了想重来 | 工具条里的**恢复默认视图** |
| 让画面保持干净 | 鼠标静止 3 秒 |
| 帮助卡 | `H` 或 `F1` |
| 保持置顶 | `T` |
| 窗口尺寸 | `S` |
| 恢复默认视图 | `R` |
| 原声 / 变声后 | `D` / `W` |
| 响度目标 | `G` |
| 让某个面板铺满窗口 | `Enter` 依次循环：声音细节 → 音量 → 声音形状 → 回到三栏 |

这个窗口可以只用键盘完成：三块面板与全部控件都有读屏名称，`Tab` 能走到各个按钮。按住 Ctrl、Alt 或 Shift 时本窗口不响应键盘快捷键，不会与 Windows 抢按键。

## 10. 你可能看到的提示

当画面无法说明全部真相时，顶部会出现一句提示。

| 提示文字 | 发生了什么 | 该怎么做 |
|---|---|---|
| "还没开启变声：请在主窗口点电源钮" | 没有可测量的处理后音频 | 在主窗口点电源按钮 |
| "麦克风没有输入：检查输入设备与虚拟音频线" | 引擎在运行，但收不到任何信号 | 检查**设置 → 输入麦克风**，并确认虚拟音频线已安装 |
| "A/B 选了 DRY：画面显示的是你的原声" | A/B 选了 **DRY**，效果链被跳过，所以表和图跟的是你未经处理的声音 | 想让画面反映听众听到的声音时，把 A/B 切回正常 |
| "监视器没能打开，可再点一次图标重试" | 打开失败 | 再点一次图标；反复出现请重启 Vonvert |

## 11. 隐私与安全

- 所有音频分析都在你的电脑上完成。监视器不向任何地方发送数据，也不收集统计信息。
- 监视器展示的关于你声音的一切，观众同样看得到。房间噪声在画面上和在音频里一样明显。
- 预设名浮层会把当前音色名展示给观众，因此音色名里不要写私人备注。
