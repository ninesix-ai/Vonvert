# 隐私政策

生效日期：2026 年 9 月 · 联系方式：privacy@vonvert.app

Vonvert 是一款 Windows 实时变声应用。**所有音频 100% 在你的本地设备上处理，麦克风音频绝不上传或传输。**

## Vonvert 不会做的事

- 不会将你的麦克风或变声后音频发送到任何地方。
- 不采集硬件指纹、遥测、分析标识或账户信息。
- 不在你的音频中嵌入水印。

## 唯一的出站网络请求

Vonvert 会定期向 GitHub 公开的 Releases API 发送一个 HTTP GET，用于检查主版本更新公告。该请求仅获取公开的发布信息，不携带任何音频、姓名、设备标识或账户信息；请求失败时应用静默跳过。

## 你的数据留在本机

- **日志** 只写入本地数据目录（数据根下的 `logs` 目录），绝不传输。
- **诊断导出**（设置 › 数据位置 › 导出诊断日志）把日志与版本信息打包为 zip，由**你**主动创建并保存。不会上传任何内容；版本快照刻意不含你的用户名、机器名与绝对路径。
- **录音与预设** 保存在你的数据目录下。你可以整体迁移数据目录（设置 › 数据位置），并在卸载时彻底清除。

## 你的选择

分享任何日志、录音或预设永远是你主动进行的操作，Vonvert 不会自行采集或上传。

## 变更与联系

本政策可能更新。如有疑问：privacy@vonvert.app 或在项目的 GitHub Issues 提出。
