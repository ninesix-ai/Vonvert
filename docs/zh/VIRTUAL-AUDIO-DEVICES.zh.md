# 虚拟音频设备：完整对比

> 语言：[English](../VIRTUAL-AUDIO-DEVICES.md) · 简体中文

本文对比了可在 Windows 上与 Vonvert 搭配使用的**虚拟音频设备**,帮助你选择适合自己环境的一款。

- 如果你只需要推荐的默认方案和分步安装步骤,请直接阅读 **[虚拟音频设备设置指南（VB-Cable）](VB-CABLE.zh.md)**。
- 如果你想详细比较**所有**可选方案,请阅读本文。

> **准确性说明：** 价格和技术细节会随时间变化。下文中的数值仅为一般性参考。请务必在各产品官方网站确认最新详情。

---

## 1. 核心术语

本文使用以下术语,含义统一定义如下。

| 术语 | 含义 |
|---|---|
| 虚拟音频设备 | 一种软件驱动程序,创建虚拟麦克风与虚拟扬声器,使音频可在不同程序之间传递。 |
| 虚拟音频线 | 虚拟音频设备的另一种叫法。本文中两个术语含义相同。 |
| Cable Input | 虚拟音频线的播放（扬声器）端。Vonvert 将变声后的音频发送至此。 |
| Cable Output | 虚拟音频线的录音（麦克风）端。聊天应用或游戏从此处读取音频。 |
| 渲染设备（Render） | Windows 中的播放设备（"扬声器"）。 |
| 采集设备（Capture） | Windows 中的录音设备（"麦克风"）。 |
| 总线（Bus） | 调音台内部的一条输出通道。 |
| 采样率 | 每秒采集的音频样本数,以 kHz 为单位。 |
| 声道 | 一路音频流。2 声道 = 立体声。 |
| ASIO | 一种低延迟音频驱动类型,主要用于音乐制作软件。 |
| WASAPI | Windows 标准音频系统。Vonvert 使用此接口。 |
| 延迟（Latency） | 声音进入系统到输出之间的时间差,越低越好。 |
| 回环（Loopback） | 将正在播放的音频重新发送给录音端,以便其他程序捕获。 |

---

## 2. Vonvert 如何使用虚拟音频设备

Vonvert 读取你的麦克风,对声音进行处理,然后将结果输出到一个**输出**设备。要让其他应用听到变声后的音频,该输出必须是虚拟音频线的 **Cable Input**。然后在聊天应用或游戏中,把对应的 **Cable Output** 设为麦克风。

**数据路径：**

```
你的麦克风
      |
      v
  Vonvert（处理变声）
      |
      v
  Cable Input  ---[ 虚拟音频线 ]---  Cable Output
                                              |
                                              v
                                    聊天应用 / 游戏（将其作为麦克风）
```

**Vonvert 自动检测规则：**
Vonvert 查找名称中包含 `CABLE`（覆盖 VB-Cable 和 Virtual Audio Cable）或 `VoiceMeeter` 的活跃**渲染设备**。找到时,状态栏显示"已检测到虚拟音频设备"。未找到时,显示可点击的"设置虚拟音频设备"链接。

任何虚拟音频设备都可以通过 Vonvert 的**设置 → 输出**手动选择使用,即使状态栏未能自动检测到它。

## 3. 设备分类

| 分类 | 功能描述 | 设备 |
|---|---|---|
| A. 简单单线 | 一条虚拟线,无控制面板,最简单。 | VB-Cable、LoopBe1、Hi-Fi Cable、Audio Repeater |
| B. 多线 + 路由 | 多条独立虚拟线,支持规则化路由。 | Virtual Audio Cable（VAC）、LoopMux、Synchronous Audio Router |
| C. 虚拟调音台 | 混合多路音频源,然后发送到虚拟总线。 | VoiceMeeter、SteelSeries Sonar |
| D. 带虚拟设备的特效套件 | 主要功能是音频效果,附带创建虚拟设备。 | NVIDIA Broadcast |
| E. Windows 内置 | 有限的回环功能,无需安装。 | Stereo Mix、WASAPI loopback（见第 7 节） |

## 5. 详细设备档案

每个设备使用相同的字段模板,方便快速对比。

### 5.1 VB-Cable（推荐默认）

- **分类：** 简单单线（A）
- **开发者：** VB-Audio
- **价格：** 免费
- **工作原理：** 创建 `CABLE Input`（播放）和 `CABLE Output`（录音）。写入输入端的音频会出现在输出端。
- **声道：** 2 进 / 2 出
- **采样率：** 48 kHz（固定）
- **ASIO：** 无
- **调音台 / 效果：** 无
- **路由自动化：** 无
- **上手难度：** 低——安装、重启、即可使用
- **优势：** 最简单；免费；几乎所有教程都支持它；适合一对一"变声→应用"场景
- **局限：** 仅一条线；格式固定；无法混音
- **下载：** <https://vb-audio.com/Cable/>

### 5.2 LoopBe1

- **分类：** 简单单线（A）
- **开发者：** VB-Audio
- **价格：** 免费
- **工作原理：** 单条低延迟播放→录音回环设备,是 VB-Cable 之前的老产品。
- **声道：** 2
- **采样率：** 48 kHz
- **ASIO：** 无
- **调音台 / 效果：** 无
- **路由自动化：** 无
- **上手难度：** 低
- **优势：** 极小极简单
- **局限：** 单条回环；已不再积极开发
- **下载：** <https://vb-audio.com/Cable/>

### 5.3 Hi-Fi Cable

- **分类：** 简单单线（A）
- **开发者：** 独立商业厂商
- **价格：** 付费
- **工作原理：** 单条虚拟线,支持更高可调音质。
- **声道：** 2
- **采样率：** 可调
- **ASIO：** 无（KS/WDM）
- **调音台 / 效果：** 无
- **路由自动化：** 无
- **上手难度：** 低
- **优势：** 比 VB-Cable 音质规格更高
- **局限：** 付费；仍只有一条线；定位类似 VAC 但灵活性不及
- **下载：** 请搜索"Hi-Fi Cable"访问厂商官网

### 5.4 Audio Repeater / SAM Virtual Audio

- **分类：** 简单单线（A）
- **开发者：** Spacial Audio
- **价格：** 免费
- **工作原理：** 将一路播放流转发到录音设备,面向广播/推流场景。
- **声道：** 2
- **采样率：** 可调
- **ASIO：** 无
- **调音台 / 效果：** 无
- **路由自动化：** 无
- **上手难度：** 中（自带控制窗口）
- **优势：** 适合广播/推流捕获
- **局限：** 设计用途为广播,非通用路由
- **下载：** <https://www.spacialaudio.com/>

### 5.5 Virtual Audio Cable（VAC）

- **分类：** 多线 + 路由（B）
- **开发者：** Eugene Muzychenko
- **价格：** 付费（约 $40；有试用版）
- **工作原理：** 创建多条独立虚拟线。后台**路由引擎**可按规则在任意设备间连接、重命名和复制音频流。
- **声道：** 每条设备最多 64
- **采样率：** 宽范围可调（约 11–192 kHz）,位深可选
- **ASIO：** 无原生 ASIO,但使用低延迟 KS 驱动
- **调音台 / 效果：** 无调音台（它是路由工具）
- **路由自动化：** 有——所有方案中最强
- **上手难度：** 中（功能强大但偏技术向）
- **优势：** 多条隔离流；自定义格式；脚本化路由
- **局限：** 付费；界面简陋；单条连接场景过于复杂
- **下载：** <https://vacutesoftware.com/>

### 5.6 LoopMux

- **分类：** 多线 + 路由（B）
- **开发者：** VB-Audio
- **价格：** 免费
- **工作原理：** 创建多条轻量虚拟播放设备,每条是简单回环,无混音。
- **声道：** 每条 2
- **采样率：** 48 kHz
- **ASIO：** 无
- **调音台 / 效果：** 无
- **路由自动化：** 仅手动
- **上手难度：** 低–中
- **优势：** 免费创建多条线；适合将一路信号分发到多个应用
- **局限：** 无混音；手动路由
- **下载：** <https://vb-audio.com/Cable/>

### 5.7 Synchronous Audio Router（SAR）

- **分类：** 多线 + 路由（B）
- **开发者：** 开源
- **价格：** 免费
- **工作原理：** 为每个运行中的应用程序分配独立的虚拟输入/输出,使不同应用使用不同的虚拟设备。
- **声道：** 2
- **采样率：** 44.1 / 48 kHz
- **ASIO：** 无
- **调音台 / 效果：** 无
- **路由自动化：** 按应用规则分配
- **上手难度：** 中
- **优势：** 免费；按应用控制路由
- **局限：** 不再积极维护；新 Windows 版本兼容性不确定
- **下载：** 在 GitHub 搜索"Synchronous Audio Router"

### 5.8 VoiceMeeter（Basic / Banana / Potato）

- **分类：** 虚拟调音台（C）
- **开发者：** VB-Audio
- **价格：** Basic 免费；Banana 采用捐赠模式；Potato 付费
- **工作原理：** 带推子的调音台。虚拟输入（`VoiceMeeter Input`、`VoiceMeeter Aux Input` 等）接收音频,混音后发送到硬件输出和虚拟**总线**（`B1`、`B2`；Potato 有 `B1`–`B5`）,总线在 Windows 中显示为录音设备。
- **声道：** 总线最多 8
- **采样率：** 44.1 / 48 kHz（可选）
- **ASIO：** 是——Banana/Potato 通过 VB-Audio ASIO 桥接支持
- **调音台 / 效果：** 是——EQ、噪声门、压缩器、混响、延迟
- **路由自动化：** 手动矩阵路由
- **上手难度：** 高——概念多；配置错误会导致静音或回声
- **优势：** 一站式混合变声、音乐、麦克风；可处理监听和录音；无需另装虚拟线
- **局限：** 学习曲线陡峭；正确配置耗时
- **Vonvert 接法：** 将 Vonvert **输出 → `VoiceMeeter Input`**,然后在聊天应用中选 `VoiceMeeter B1 Out` 作为麦克风。
- **下载：** <https://vb-audio.com/Voicemeeter/>

### 5.9 SteelSeries Sonar

- **分类：** 虚拟调音台（C）
- **开发者：** SteelSeries
- **价格：** 免费
- **工作原理：** 虚拟 7.1 调音台,按命名总线（Game、Chat、Media、Mic 等）管理音频。面向游戏和直播。
- **声道：** 立体声,附带虚拟 7.1 空间音效
- **采样率：** 48 kHz
- **ASIO：** 无
- **调音台 / 效果：** 是——按总线均衡和预设
- **路由自动化：** 手动
- **上手难度：** 中
- **优势：** 游戏/聊天分离简单；有音效润色；免费
- **局限：** 属于 SteelSeries GG 软件；灵活性不及 VAC/VoiceMeeter
- **下载：** <https://steelseries.com/gg/sonar>

### 5.10 NVIDIA Broadcast

- **分类：** 带虚拟设备的特效套件（D）
- **开发者：** NVIDIA
- **价格：** 免费（需要 NVIDIA 显卡）
- **工作原理：** 主要功能是 AI 效果——降噪、去房间回声、视频自动取景。附带创建虚拟麦克风和虚拟扬声器。
- **声道：** 2
- **采样率：** 48 kHz
- **ASIO：** 无
- **调音台 / 效果：** 特效,非通用调音台
- **路由自动化：** 无
- **上手难度：** 低
- **优势：** 降噪效果出色；可作为 Vonvert 前级净化
- **局限：** 需要 NVIDIA 硬件；非路由工具；默认设备名不含 `CABLE` 或 `VoiceMeeter`,Vonvert 不会自动检测（需手动选择）
- **下载：** <https://www.nvidia.com/en-us/geforce/broadcasting/broadcast-app/>

## 6. 如何选择

| 你的目标 | 推荐设备 |
|---|---|
| 把变声送进一个聊天应用或游戏 | **VB-Cable** |
| 混合变声、背景音乐、麦克风,同时推流/录制 | **VoiceMeeter Banana / Potato** |
| 多条独立隔离音频流、自定义格式或规则化路由 | **Virtual Audio Cable（VAC）** |
| 将一路信号免费分发到多个应用 | **LoopMux** |
| 先做好麦克风降噪,变声次要 | **NVIDIA Broadcast** + **VB-Cable** |
| 按应用分配路由,免费,非关键场景 | **SAR**（先确认兼容性） |

**总结：** 对大多数 Vonvert 用户,**VB-Cable 是最佳默认选择**——免费、简单、文档支持最广。需要混音选 **VoiceMeeter**,需要多线或自动化选 **VAC**。

## 7. Windows 内置方案（有限）

以下不是可安装的虚拟声卡,但有时会被提及：

- **Stereo Mix：** 老旧的驱动功能,可录制电脑正在播放的声音。很多现代声卡已不提供此选项。
- **WASAPI loopback：** 一种编程方式,在应用内部捕获播放流。**不会**生成可选设备。Vonvert 的*监听自己（Hear Myself）*功能使用此类捕获方式,而非虚拟音频线。

---

## 8. 任何设备的通用注意事项

- **管理员权限：** 虚拟音频设备是系统驱动,安装需要管理员权限,安装后通常需要**重启**设备才会出现。
- **设备未列出：** 在 Vonvert 设备设置中点击**刷新**,或检查 **Windows 设置 → 系统 → 声音**。
- **回声 / 啸叫：** 使用耳机,或关闭*监听自己（Hear Myself）*。
- **许可证：** 以上均为第三方产品,有各自独立的许可证,不属于 Vonvert 的 Apache-2.0 许可证。
