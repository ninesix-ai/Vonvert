# Vonvert 用户使用指南

> Language: [English](../USER-GUIDE.md) · 简体中文

这是 **Vonvert**（Windows 实时变声器）的完整用户使用指南，涵盖从首次安装到
进阶调声的全部内容。若你只想最快跑通，请直接看**第一部分 → 第 3 章（快速上手）**。

- Vonvert 在你**说话的同时**改变你的声音，并可把变声后的音频送入任意应用
  （聊天、会议、游戏、直播）。
- 音频全部在**你自己的电脑上**处理，见[第 15 章 · 隐私与数据](#隐私与数据)。

# 第一部分　入门

## 第 1 章　认识并安装 Vonvert

### 1.1 Vonvert 是什么

#### 1.1.1 它能做什么
- 实时采集你的**麦克风**。
- 把声音经过一条**DSP 链**（音高、EQ、混响、合唱、压缩、机器人、失真等）。
- 把变声结果输出到你选择的设备——通常是**虚拟音频线缆**，从而让其他应用把它
  当作一个普通麦克风。

#### 1.1.2 信号链路
```
你的麦克风
      |
      v
   Vonvert （实时 DSP：音高 / EQ / 混响 / ...）
      |
      +--> CABLE Input ---[ 虚拟线缆 ]--- CABLE Output
                                                  |
                                                  v
                                    你的聊天应用 / 游戏（作为它的麦克风）
      |
      +--> （可选）监听自己  --> 你的耳机（本地监听）
```
虚拟线缆是可选的，但强烈建议安装——见[第 5 章](#第-5-章音频路由把变声送入其他应用)。

#### 1.1.3 关键术语
| 术语 | 含义 |
|---|---|
| 预设（声线） | 一组现成的效果参数组合，如**女声**、**恶魔**。 |
| 干声 | 你原始、未经处理的麦克风声音。 |
| 湿声 / 处理后 | 应用效果之后的声音。 |
| 虚拟音频设备（线缆） | 软件模拟的"假麦克风 + 假扬声器"，用于在应用间传声（VB-Cable、VoiceMeeter、VAC）。 |
| Cable Input / Cable Output | 虚拟线缆的扬声器端与麦克风端。 |
| 延迟 | 从说话到输出/听到的时间差，越低越好。 |
| VU 表 | 底部栏的输入/输出电平条。 |

### 1.2 本指南的约定

#### 1.2.1 版本与许可
本指南面向 GitHub 上的 **开源（OSS）版** Vonvert，采用 **Apache License 2.0**。
其他指南中提到的部分功能（试用、授权、额外效果器）属于其它版本，不含在本构建中。

#### 1.2.2 符号
- ✓ 支持 · ✗ 不支持 · – 不适用。

#### 1.2.3 保持原样的名称
产品名、设备名、文件名、按键名与 URL 一律不翻译。

### 1.3 准备与安装

#### 1.3.1 系统要求
- Windows 10 或 Windows 11。
- 一个麦克风与耳机/音箱（用耳机可减少回声——见[第 14 章](#第-14-章故障排查)）。
- 可选但建议：一个虚拟音频设备，如 VB-Cable。

#### 1.3.2 硬件
请在启动 Vonvert **之前**插好麦克风和耳机；若设备未列出，到设置里点
**↻ 刷新设备**。

#### 1.3.3 下载与安装
- **免安装：** 直接运行 `Vonvert.exe`，无需安装。
- **安装器（可选）：** 用户级安装包装到 `%LOCALAPPDATA%\Programs\Vonvert`，
  **不需要**管理员权限。
- 从源码构建、测试与打包属于开发者内容，见仓库 `README.md`。

#### 1.3.4 （可选）虚拟音频设备
要让其他应用听到你的变声，请一次性安装一个虚拟音频设备。本指南**不重复**其安装
步骤，请参阅：
- **[VB-CABLE 设置指南](VB-CABLE.zh.md)** —— 推荐默认，手把手。
- **[虚拟音频设备对比](VIRTUAL-AUDIO-DEVICES.zh.md)** —— 横向比较所有方案。

## 第 2 章　首次启动：设置向导与角色

Vonvert 第一次启动时会先显示一个简短的设置向导，然后是聚光灯巡览。两者都**只跑
一次**：Vonvert 会在[数据位置](#103-数据位置)写入名为 `onboarding_done` 的标记
文件，此后只要该文件存在就跳过向导。

### 2.1 设置向导

共 4 步，任意一步都可点**跳过**：

| 步骤 | 标题 | 你要做的 |
|---|---|---|
| 1 | **欢迎使用 Vonvert** | 无需操作，点**下一步**。 |
| 2 | **你打算如何使用 Vonvert？** | 选一个角色（见 §2.3），或选**不使用角色（显示全部）**。 |
| 3 | **选择你的设备** | 选择麦克风与输出设备（例如 VB-Cable）。 |
| 4 | **一切就绪** | 点**开始使用**关闭向导。 |

底部显示进度**第 N / 4 步**，**上一步**可回退。

### 2.2 聚光灯巡览

向导结束后紧接一段**快速上手**：窗口变暗，依次高亮四处。读完说明点**下一步**，
最后点**完成**：

1. *点击任意音色即可变声，悬停可试听。*
2. *这个电源按钮用来开启或关闭变声。*
3. *选中音色后，这里可展开调节音高、均衡等细节。*
4. *在这里选择你的麦克风和输出设备（例如 VB-Cable）。*

### 2.3 角色

角色决定你看到哪些控件、以及推荐哪些音色。共 8 个角色，分属**游戏娱乐**、
**内容创作**、**专业音频**三组：

| 角色 | 分组 | 定位 | 默认复杂度 |
|---|---|---|---|
| **新手** | 游戏娱乐 | 就是想先试试看。 | 极简 |
| **游戏玩家** | 游戏娱乐 | 为游戏和 Discord 准备的趣味音色。 | 标准 |
| **主播** | 内容创作 | 直播与实时变声。 | 标准 |
| **创作者** | 内容创作 | 录制与内容制作。 | 标准 |
| **配音演员** | 内容创作 | 角色与配音工作。 | 进阶 |
| **社交变声** | 游戏娱乐 | 聊天应用里的趣味音色。 | 极简 |
| **音频工程师** | 专业音频 | 掌控每一个参数。 | 专业 |
| **AI 爱好者** | 专业音频 | 折腾 AI 语音工具。 | 专业 |

四档复杂度依次是**极简**、**标准**、**进阶**、**专业**。角色给的只是起点，随时
可在**设置 → 我的角色**（[§10.6](#106-我的角色)）改。

### 2.4 再次运行向导

设置里**没有"重玩引导"按钮**。想再看一遍，请退出 Vonvert 并删除标记文件：

```
%APPDATA%\ninesix-ai\Vonvert\onboarding_done
```

重启后即会重新出现。（若改过数据位置，文件在你所选的目录下。）

## 第 3 章　快速上手（5 分钟）

### 3.1 首次启动与窗口
界面分为三块：
- **左侧图标栏** —— 在**变声**、**设置**、**关于**之间切换。
- **中间内容区** —— 声线选择器与实时可视化。
- **底部栏** —— 品牌 + 状态、一个大的**变声**开关按钮，以及输入/输出 **VU** 表
  和**延迟**读数。

标题栏（右上角）是常规的**最小化 / 最大化 / 关闭**。点**关闭**会把 Vonvert
最小化到**系统托盘**而非退出（右键托盘图标 → **退出** 才彻底关闭）。

### 3.2 三步出声
1. **选设备** —— 设置里把**输入麦克风**选为你的真实麦克风，把**输出（推荐 VB-Cable）**
   选为 `CABLE Input (VB-Audio Virtual Cable)`。
2. **打开变声** —— 点底部栏的**变声**按钮。
   - 生效时显示 **运行中（效果开启）**。
   - 关闭时显示 **待机（直通监听）** —— 声音仍然直通，只是不变声。
3. **选声线并说话** —— 点一个声线磁贴（启动时会自动应用**女声**）。对麦克风说话，
   **输入/输出**电平条会跳动。

> 应用内提示：*"选一个声线，然后对麦克风说话——开箱即用，效果默认开启。"*

### 3.3 自检
- 说话时**输入**条应跳动 → 麦克风已被采集。
- **输出**条应跳动 → 正在产出音频。
- 若别人仍听到你的原声，见[第 5 章](#第-5-章音频路由把变声送入其他应用)。

# 第二部分　日常使用

## 第 4 章　声音预设

### 4.1 内置预设
Vonvert 自带 8 个声线，点磁贴即生效，并有气泡提示"已应用预设：…"。

| 预设（中） | English | 图标 | 特点 |
|---|---|---|---|
| 原声 | Normal | 🎙️ | 干净直通（仅门限 + 压缩） |
| 低沉男声 | Deep Male | 🎺 | 音高更低、低频更暖 |
| 女声 | Female | 🌸 | 音高更高、更明亮、去齿音（启动默认） |
| 机器人 | Robot | 🤖 | 环形调制的机器人音色 |
| 恶魔 | Demon | 😈 | 极低音高，叠加失真与混响 |
| 仿生人 | Android | 🦾 | 金属感的环形调制人声 |
| 电台残响 | Radio Ghost | 📻 | 带宽受限的电台音色带尾音 |
| 磁带摇曳 | Tape Wobble | 📼 | 音高漂移的 Lo-Fi 磁带质感 |

> 内置预设是**只读**的——不能删除或覆盖。

### 4.2 选择与切换
- **点**一个磁贴即应用。
- 按 **F11**（默认）循环切换到**下一个预设**，无需动鼠标。
- 想了解每个预设内部改了什么，见[第 13 章](#第-13-章理解声线dsp-效果)。

### 4.3 导入、导出与删除预设
声线选择器磁贴下方有 **导入** 和 **导出** 两个按钮：
- **导出** 把当前选中的预设写成一个 `Vonvert 预设 (*.vopreset)` 文件，便于分享或备份。
- **导入** 读取别人分享的 `.vopreset` 文件并加入你的选择器。
- 要**删除**你添加的预设，**右键它的磁贴** → **删除** 并确认；内置预设无法删除。
- 若文件无效，会提示"导入失败——不是有效的预设文件"。

## 第 5 章　音频路由：把变声送入其他应用

### 5.1 原理
Vonvert 把变声写入一个**输出**设备。要让其他应用听到它，这个输出必须是某条
**虚拟线缆的 Input**，而该应用的麦克风必须是同一条线缆的 **Output**。

### 5.2 选择设备
- **VB-Cable（推荐）** —— 一根线，最简单，见 **[VB-CABLE 设置指南](VB-CABLE.zh.md)**。
- **VoiceMeeter** —— 完整虚拟调音台，适合同时混背景音乐或多麦克风，见
  **[对比指南](VIRTUAL-AUDIO-DEVICES.zh.md)**。
- **VAC 等** —— 多路独立线缆、专业路由，见 **[对比指南](VIRTUAL-AUDIO-DEVICES.zh.md)**。

> Vonvert 会自动检测名称含 **CABLE** 或 **VoiceMeeter** 的活动输出；否则请在
> **设置 → 输出** 里手动选择。

### 5.3 各应用如何设置
在每个应用里，把它的**麦克风 / 输入设备**设为 `CABLE Output`：

| 应用 | 在哪里设置 |
|---|---|
| Discord | 设置 → 语音和数据 → **输入设备** |
| Zoom | 设置 → 音频 → **麦克风** |
| Teams | 设置 → 设备 → **麦克风** |
| OBS | 来源 → 音频输入捕获 → **设备** |
| 游戏 | 游戏内音频/语音设置 → **输入 / 麦克风** |

> 具体菜单名因应用版本而异。

## 第 6 章　监听、对比与实时表头

### 6.1 监听自己（听到你自己的变声）
**设置 → 监听自己** 开启一个本地监听，让你在说话时于耳机里听到自己的
**变声后**声音。
- **开** = 本地听到处理后的声音。
- **关**（默认）= 只有输出线缆带着它走，本地听不到。
- 若出现回声/啸叫，请**关掉**它或改用耳机。

> **监听自己**不改变*输出内容*——它只决定这份音频是否额外送回你的耳机。它与下面的
> A/B 控制配合使用。

### 6.2 A/B 对比（原声 / A/B / 全效果）
变声页右上角的分段控制改变**输出里装的是什么**：

| 按钮 | 你听到 | 用途 |
|---|---|---|
| **原声**（DRY） | 你原始未处理的声音 | 判断效果把你改了多少 |
| **A/B**（Normal） | 完整的处理后声音（别人听到的） | 日常使用 |
| **全效果**（WET） | 只有效果叠加的部分（处理 − 干声） | 听清单个效果的"染色" |

- **原声 + 监听自己** = 听到你的裸声。
- **A/B + 监听自己** = 听到你的变声。
- 切回 **A/B** 即恢复正常效果输出。

> **全效果**是相减（处理结果减去干声），所以听起来偏虚——这是正常的，它用于对比，
> 不适合日常。

### 6.3 实时可视化
引擎运行时，变声页显示：
- **频谱** —— 实时频谱，右上角显示检测到的**音名**与**音分**偏差。
- **音高** —— 一小段随时间变化的音高曲线。
- 底部栏的 **输入 / 输出** VU 条与 **延迟：… ms** 读数。

这些只作反馈，无需配置。

## 第 7 章　快捷键与按键通话

### 7.1 默认快捷键
全局快捷键即使在 Vonvert 未聚焦时也生效。

| 动作 | 默认键 | 界面标签 |
|---|---|---|
| 变声开 / 关 | **F9** | 开关 |
| 静音（输出静音） | **F10** | 静音 |
| 下一个预设 | **F11** | 下一个预设 |
| 按键通话 | **F12** | 按键通话 |

### 7.2 改键、冲突与重置
在**设置 → 快捷键**：点某个快捷键按钮，再按一个新键（修饰键组合或功能键 F）。
若该键已被占用，会提示"冲突：已绑定到 …"。点 **↻ 恢复默认** 可还原为 F9–F12。

### 7.3 对讲模式
**设置 → 对讲模式** 决定按键通话的作用：
- **按住说话** —— 平时静音，**仅按住**按键时才对外出声。
- **按住静音** —— 平时正常说话，**仅按住**时闭麦。

提示文字为"按住 {键} 时："，会跟随你当前的对讲键绑定。

## 第 8 章　音效板

**音效板**标签页用于在你说话之外叠加一次性音效。内置 **50 个音效**，全部由引擎
程序化生成，不附带任何第三方音频文件。

### 8.1 打击垫

用左侧分类 Chip 过滤，各分类及数量为 **鼓组** 9、**音色** 5、**音效** 13、
**梗音效** 5、**音乐** 6、**复古** 5、**环境** 7。

每个打击垫显示图标、名称、时长与热键徽章。时长按听感分档书写：不足 1 秒取整毫秒
（`50ms`），1 到 10 秒保留一位小数（`1.2s`），10 秒及以上取整秒（`30s`）。

点击打击垫即播放。

### 8.2 试听与直播

右上角两枚胶囊决定**谁能听到音效**：

| 模式 | 谁能听到 |
|---|---|
| **试听** | 只有你自己，从你自己的扬声器。 |
| **直播** | 你，**以及**通话或直播另一端的人。 |

直播模式下，音效会混入 Vonvert 发往虚拟音频设备的同一路线输出，因此聊天应用和
游戏会连同你的声音一起转发出去。胶囊下方有一条常驻状态条，始终说明当前状态：

- *试听中：音效只从你自己的扬声器出声，对方听不到。*
- *直播中：音效会混入发往虚拟音频设备的输出，通话或直播时对方也能听到。*
- *已选直播，但变声引擎未启动——现在没有人能听到任何声音。*

引擎未启动时第三条优先显示：直播依赖引擎输出，引擎不跑就没人听得到。而**试听走
独立播放通道，引擎停着也能响**，所以上播前可以先安心试听。

处于直播模式时，状态条上还会出现**切回试听**，误开时可一键退出。

> 音效是在人声效果链**之后**混入的，因此不会被变调。不管你在用哪个音色，底鼓
> 听起来始终是底鼓。

**音量**（右上角滑杆）作用于所有音效，与麦克风增益相互独立。

### 8.3 你自己的音频

点**导入**添加音频文件，支持 `.wav`、`.mp3`、`.ogg`、`.m4a`。导入的音效归入
**导入**分类。要移除，点打击垫角上的 **✕** 并确认（**移除**）。

### 8.4 每个打击垫的热键

点击打击垫的热键徽章（**绑定热键**），然后按下组合键——提示为*按下组合键以绑定
该音效。*该绑定与其他[快捷键](#第-7-章快捷键与按键通话)一样是全局的，切到别的
应用也能触发。**右键**点击打击垫可清除（**清除热键**）。

## 第 9 章　录音与导出

**录音**标签页把音频保存到本地，便于留存或分享。

### 9.1 录制内容

开始前先选**模式：**：

| 模式 | 录到的内容 |
|---|---|
| **原始** | 未经处理的麦克风声音。 |
| **变声后** | 经过 Vonvert 效果处理的声音，即别人听到的那份。 |

### 9.2 录音

点**● 开始录音**。首次会要求确认：

> **录音提示**
> 录音会在你的电脑上保存音频。请仅录制你有权保存的音频。是否继续？

录制中按钮变为**■ 停止**，**取消**则丢弃当前这段。点**■ 停止**结束并保存，随后
出现*录音已保存*提示。

录音保存在 Vonvert 的[数据位置](#103-数据位置)内，不与程序放在一起。

### 9.3 历史列表

已保存的录音列在**录音历史**下，每条显示时长与大小。可以：

- 用**搜索录音…**按文件名查找。
- 按日期筛选：**今天**、**7 天**、**30 天**。
- 按时长筛选：**< 1 分钟**、**1–5 分钟**、**5–15 分钟**、**> 15 分钟**。
- 看汇总行，例如 *{0} 个录音 • 总时长 {1} • {2}*。

勾选多行后点**删除所选**可一次移除；Vonvert 会问*确定删除所选的 N 个录音？此操作
无法撤销。*，完成后报*已删除*。未勾选任何条目时会提示*未选择任何项目*。

### 9.4 导出

点某行的**导出**打开**导出录音**，选择保存位置与格式：

| 格式 | 特点 |
|---|---|
| **WAV** | 无压缩，体积最大，完全一致。 |
| **MP3** | 体积小，几乎到处能放。 |
| **FLAC** | 压缩但无损。 |
| **OGG** | 体积小，开放编码。 |
| **AAC / M4A** | 体积小，苹果系友好。 |

还可选择**单声道**或**立体声**，并在有损格式下开启**使用可变比特率 (VBR)**。
成功提示*导出完成*，失败提示*导出失败*。

> 导出走的是与实时链路**相同的限制器链**，因此成品不会比听众实际听到的更响。

### 9.5 删除

单行的**删除**会先问*确定删除此录音？此操作无法撤销。*再执行。

## 第 10 章　设置与个性化

从左侧栏打开**设置**。所有选择重启后仍保留。

### 10.1 音频设备
- **输入麦克风** —— 你的真实麦克风。
- **输出（推荐 VB-Cable）** —— 变声送往的设备。
- **↻ 刷新设备** —— 插好设备后重新扫描。
- 状态行显示 **已检测到虚拟音频设备**，或一个可点的 **"设置虚拟音频设备 →"** 链接。

### 10.2 界面语言
**语言** 立即在 **English** 与 **中文** 之间切换整个界面。首次启动时 Vonvert 跟随
你的 Windows 显示语言（zh-\* → 中文，否则英文），你的选择会被保存。

### 10.3 数据位置
**数据位置** 是你的**预设、设置与日志**存放处。
- **更改…** 可选择另一个文件夹。
- 随后会询问是否把现有数据**复制**到新位置。
- 更改**需重启 Vonvert 后生效**。
- 默认位于 `%APPDATA%\ninesix-ai\Vonvert`（带发布者命名空间，因此不会与其他
  Vonvert 版本互相冲突）。也可用上面的**更改…**指向别处。

### 10.4 托盘与后台
关闭窗口会把 Vonvert 送到**系统托盘**，引擎继续运行。双击托盘图标（或右键 →
**打开**）恢复窗口，右键 → **退出** 关闭程序。

### 10.5 关于、版本与更新
**关于**页显示版本、运行时与依赖信息，并提供**复制全部**按钮以便求助。当有
新的**主版本**公告时，底部栏会出现一个徽章；点击它会打开发布页（其联网行为见
[第 15 章 · 隐私与数据](#隐私与数据)）。

### 10.6 我的角色

**设置 → 我的角色** 显示你在[设置向导](#第-2-章首次启动设置向导与角色)里选定的
角色，并可随时更改。角色影响两件事：

- **复杂度**——**极简** / **标准** / **进阶** / **专业** 四档之一，决定界面暴露
  多少控件。
- **推荐音色**——该角色建议使用的内置预设。

选**不使用角色（显示全部）**可让 Vonvert 不再做任何裁剪，无论复杂度都显示全部控件。

> 更改角色不会删除任何预设或录音；它只改变显示哪些控件、推荐哪些音色。

# 第三部分　进阶调声

## 第 11 章　专家参数面板

选中一个音色后，变声页右侧会展开面板，逐项暴露它背后的参数——音高偏移、均衡各
频段、压缩阈值、混响大小等。

### 11.1 简易与专业

面板顶部的下拉框决定看到多少：

| 模式 | 显示范围 |
|---|---|
| **简易** | 只列日常用得上的分组。 |
| **专业** | 引擎支持的全部分组。 |

这份清单与效果器目录同源生成，因此引擎一旦认识某个参数，这里就会自动出现。

### 11.2 保存你调的结果

改动即时生效并作用于正在运行的音频。

- **另存为…** 把你的调整存成一个**新的**预设，之后可选用，也可从 §4.3 导出。
  内置预设永不被覆盖。
- **恢复为预设** 丢弃你的调整，还原当前预设的原始数值。

### 11.3 与预设的关系

预设是一整包效果参数；本面板编辑的是你当前加载的那一包。想整体听出某个预设带来
的变化，用 A/B 对比（见 §6.2）；想了解每个控件的作用，见
[第 13 章](#第-13-章理解声线dsp-效果)。

## 第 12 章　自动音高（音区归一化）

**自动音高**（变声页顶部）"使用实时 F0 检测将音高归一化到目标音区"。通俗讲，
它让你的输出保持在一个稳定的音域、不再漂移，从而让大幅变调（如**女声**或**恶魔**）
更稳。若你的声音忽高忽低就开启它；若想保留每一处自然起伏就关掉。

## 第 13 章　理解声线（DSP 效果）

Vonvert 通过**预设**套用效果——预设是你直接挑选、而非从零搭建的一整包参数。
每个预设仍可在[专家参数面板](#第-11-章专家参数面板)里逐项微调。了解每个效果的
作用，能帮你挑选、调校或分享预设。

### 13.1 各效果的作用
| 效果 | 作用 |
|---|---|
| **音高 Pitch** | 以半音为单位升高/降低声音。 |
| **均衡 EQ** | 提升或衰减低频/中频/高频。 |
| **混响 Reverb** | 增加空间/房间尾音。 |
| **合唱 Chorus** | 叠厚声音，更饱满。 |
| **压缩 Compressor** | 平衡大声与小声的电平。 |
| **噪声门 Gate** | 不说话时静音背景噪声。 |
| **降噪 Noise Reduction** | 去除持续的底噪/嗡鸣。 |
| **延迟 Delay** | 增加回声。 |
| **齿音消除 De-esser** | 抑制刺耳的 "s" 音。 |
| **机器人 Robot** | 环形调制的金属质感人声。 |
| **失真/过载 Drive** | 增加毛刺与饱和度。 |
| **环形调制 Ring Mod** | 用正弦波乘以人声；金属感、合成质感。 |
| **Lo-Fi 混响** | 被压碎、降采样的空间，尾音很短（电台/磁带损坏质感）。 |
| **调制延迟** | 时间被扫描的延迟，产生音高漂移/合唱式摇曳。 |
| **斜率均衡 Tilt EQ** | 让整体频谱低频向下、高频向上倾斜（或反向）。 |
| **图形均衡 Graphic EQ** | 多频段手动均衡。 |
| **位深破碎 Bitcrusher** | 数字量化噪声；刻意的 lo-fi 毛刺。 |
| **响度表 Loudness Meter** | 测量输出电平，不改变声音。 |

### 13.2 每个内置预设用了什么
| 预设 | 效果配方 |
|---|---|
| **原声** | 仅 噪声门 + 压缩（干净） |
| **低沉男声** | 音高 −4 · EQ（低频 +3，高频 −2）· 压缩 |
| **女声** | 音高 +4 · EQ（削减低频、提升临场感/空气感）· 压缩 · 合唱 · 齿音消除 |
| **机器人** | 机器人 · 音高 −2 · 轻混响 |
| **恶魔** | 音高 −9 · 失真 · 混响 · 噪声门 |
| **仿生人** | 环形调制（载波 120 Hz，混合 0.6）· 噪声门 · 压缩 |
| **电台残响** | Lo-Fi 混响（空间 0.7 · 衰减 0.7 · 降采样 8 · 位深 5 · 混合 0.5）· 噪声门 · 压缩 |
| **磁带摇曳** | 调制延迟（基准 18 ms · 深度 0.7 · 反馈 0.35 · 混合 0.45）· 噪声门 · 压缩 |

### 13.3 调声工作流
预设是整套打包的，所以先靠**选择**一个预设起步。要更进一步，就打开
[专家参数面板](#第-11-章专家参数面板)逐项调整，再用**另存为…**把结果存成你自己的
预设。用 **A/B 对比**（见 §6.2）听清某预设到底加了什么：在 **原声** 与 **A/B**
间切换以判断改动量，或用 **全效果** 单独听染色。把你喜欢的预设**导出**（见 §4.3）
以备份或分享。

# 第四部分　支持与参考

## 第 14 章　故障排查

| 症状 | 检查什么 |
|---|---|
| 完全没有声音 | Vonvert **输出**设为 `CABLE Input`；说话时**输出** VU 条跳动。 |
| 别人听到的是原声 | 应用的**麦克风**设为 `CABLE Output`，而非你的真实麦克风（见 §5.3）。 |
| 一直像"原声" | 分段控制停在 **原声** 上；切回 **A/B**。 |
| 变声没效果 | 底部**变声**按钮需显示 **运行中（效果开启）**；若显示 **待机（直通监听）** 就点它。 |
| 回声 / 啸叫 | **关闭** *监听自己*，或改用耳机。 |
| 延迟高 / 断续 | 在系统音频设置里调小缓冲区；关闭占用大的程序；看**延迟**读数。 |
| 设备列表里没有 | 点 **↻ 刷新设备**；查 Windows **设置 → 系统 → 声音**。 |
| "未检测到麦克风" | 插入麦克风后点 **刷新设备**。 |
| 缺少 `CABLE Input/Output` | 虚拟线缆驱动未装好——见 [VB-CABLE 设置指南](VB-CABLE.zh.md)（**以管理员身份**运行安装并重启）。 |

### 15.2 隐私与数据
- **音频留在你本机。** Vonvert 在本地处理你的声音，**不会**上传你的语音。
- **本地保存了什么：** 你的设置、所选设备、语言以及导入的预设，都存放在
  **数据位置**（默认 `%APPDATA%\ninesix-ai\Vonvert`，可在 §10.3 更改）。
- **联网行为：** 唯一的自动联网，是周期性地向 GitHub 发布页做一次轻量、尽力而为的
  **更新检查**，用于提示新的**主版本**。它定时触发、失败时静默忽略，且**不发送任何
  语音数据**。点击更新徽章、托盘链接或应用内帮助链接，会在你的浏览器打开普通网页。
