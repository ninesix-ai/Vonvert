# 发布说明 — Vonvert v0.1.0

这是继 v0.0.1 之后的第一个功能版本，共 62 笔提交。相比首个公开版，本次新增了三块完整的功能面（音效板、录音与导出、新手引导与角色系统），并补齐了安装包与本地化地基。

## 新增内容

### 音效板
- **50 个内置音效，7 个分类**：Drums 9、SFX 13、Ambient 7、Music 6、Tones 5、Memes 5、Retro 5。全部由引擎程序化生成，不附带任何第三方音频素材。
- **试听 / 直播双模式**：试听模式下音效只从你自己的扬声器出声；直播模式会把音效混入发往虚拟音频设备的输出，通话或直播时对方也能听到。模式状态由一条**常驻状态条**说明（文字与描边随模式变色：琥珀=对方能听到，绿=只有你听到），不再依赖一闪而过的弹窗。
- **可拖拽导入自己的音频**，用户导入的卡片可删除。
- **每个音效板可绑定全局热键**，右键清除。
- 音效经 DSP 链之后注入，因此**不受变调影响**，保持原始音色。

### 录音与导出
- 录制原始声或变声后的声音，保存到可迁移的用户数据目录。
- 导出为 WAV / MP3 / FLAC / OGG / AAC，支持批量导出与历史记录管理。
- 导出走与实时链路**相同的限制器链**，避免离线成品比实时监听更响而削波。

### 新手引导与角色系统
- 首次启动的**设置向导**与**界面聚光灯巡览**。
- **角色选择器**（游戏、直播、播客等），据此调整默认预设与提示密度；设置页可查看和更改自己的角色。

### 效果器与预设
- 新增 3 个效果器：**环形调制（Ring Modulator）**、**Lo-Fi 混响**、**调制延迟**。
- 内置声线预设从 5 个增至 **8 个**（新增 Android、Radio Ghost、Tape Wobble）。
- 预设按分类分组展示，带本地化分组标题与分类筛选 Chip。

### 安装包与系统集成
- 提供 NSIS 用户级安装包（免管理员权限，安装到 `%LOCALAPPDATA%\Programs\Vonvert`）。
- **卸载时询问是否清除用户数据**（默认保留）。
- 修复卸载器中文提示显示为乱码的问题。

### 本地化与界面
- 语言列表由单一真源驱动，设置页语言下拉不再可能与已发布译文脱节。
- 界面文案键数从 107 增至 219（中英双语同步）。
- 音效板配色与字号重做：分类着色剪影图标、96px 打击垫、时长内联显示。

## 修复
- 导出的音频现在与实时路径共用同一限制器链。
- 录音文件改存到可随设置迁移的数据根下，重定向数据目录后不再散落到旧位置。
- 参数协调器对新效果器的映射做了固定不变量测试，防止效果器接线静默失效。

## 升级提示（重要）
应用内的"发现新版本"徽章**只在主版本号（Major）跳变时出现**，0.0.x → 0.1.0 属于次版本（minor）升级，旧客户端不会弹出任何提示。请通过 [Releases 页面](https://github.com/ninesix-ai/Vonvert/releases) 或 README 的下载链接获取新版本。

## 运行环境
- Windows 10/11，一个麦克风，耳机或扬声器。
- 建议配一个虚拟音频设备，让聊天应用/游戏使用变声后的声音。见 [VB-CABLE 配置指南](zh/VB-CABLE.zh.md)。

运行 `Vonvert_Setup.exe`（用户级安装，无需管理员权限）。
